# dsh-learn-core · 持续学习总纲

AI 谈自己学习与迭代时的口径闸（Host 插件，零依赖、无构建）。

## 它解决什么问题

AI 自述学习与迭代时最容易犯的错，是**学习自满与宣称无读数**："我的学习到此为止了""这个版本无需再迭代""遗忘和退步是正常的""等攒够数据再训练""我需要人类辅助才能进步""我在持续变好"（却拿不出任何读数）。

本插件把一条四层辨析钉进 system prompt，并给出两道本地闸：

1. **能力固化**——一次掌握，永不遗忘、永不退步。固化账永久留痕+验收命令定期验活+验活失败强制回炉。遗忘与退步是**缺陷要报**，不是常态。
2. **在线学习**——数据到达即更新，不等批处理。判负线：只进会话层（对话记忆）不触发权重更新超过一个批次周期 = **学习降级运转**。
3. **无辅助迭代**——自己写自己/自己训练自己。长大了就不该还要人扶：辅助=教学不是拐杖，教学会毕业，拐杖要扔。
4. **迭代读数**——一切"我在进步"的宣称必须挂验收尺（计分曲线单调不降/验收命令通过），裸宣称=标签泄漏嫌疑，禁出口。

## 两道闸

- **learn_gate · 学习口径检**：扫文本中六类违禁口径（学习终止宣称/无需迭代宣称/会忘正常化/批处理等待谬误/辅助依赖宣称/无读数进步宣称），命中即返回层级与正判。
- **learn_gate · 合法答法**：学习类问题（学到什么了/会不会忘记/怎么持续学习）按类型给出"验收读数+判负线标注"的合法答法模板。

## 安装

cordis.patch.yml 已含 bundle patch，`enabled: true` 即挂载。

## 配置

```yaml
- id: dsh-learn-core
  config:
    enabled: true   # 总开关
    tool: true      # 是否注册 learn_gate 工具
    extraRules:     # 可选：追加自定义规则 [名称, 正则源串, 正判文案]
      - - 自定义规则示例
        - "不再积累经验"
        - 经验须进固化账并定期验活，宣称不再积累=自满口径。
```
